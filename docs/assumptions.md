# Assumptions

- Every release: 14th of observation month + 2. Approximate; actual first-release
  dates and original vintages are not reconstructed. Revised values remain labelled.
- History starts April 2023 for weekly lags; comparable CWT and evaluation
  outcomes start October 2023. Backtest origins start January 2024.
- Core membership requires an observed backlog in the evaluation era. This is
  a fixed retrospective cohort, not a reconstructed roster at every origin.
- Location markers represent headquarters or a stated hospital postcode;
  historical trust codes/names need not represent today's organisational structure.
- USC first attendances are not referrals received. DM01 includes non-cancer demand.
- The empirical interval targets 80% coverage; measured coverage can differ.
- Strike capacity factor 0.952 remains an unverified, editable future simulation
  assumption, not a measured trust cancer-capacity effect. Strike dates are not yet used.
- No personal waits, causal recommendations or lives-saved estimates.
